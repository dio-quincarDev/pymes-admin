    Flujo offline (2026-09-18)¶

    1. Online: JWT en localStorage + pymeq_last_sync update por cada api response OK
    2. SW cachea GET /api/v1/core/* con StaleWhileRevalidate → offline sirve cache + banner datos desactualizados · última sync HH:mm
    3. Sin red: writes fallan con OFFLINE (ERR_NETWORK/!navigator.onLine) sin hacer logout; token expira offline → encola, no revoca, reintenta al volver
    4. Al volver: online event → notify + lastSync update → siguiente GET refresca SWR

    Estrategia de Instalación PWA Multi-Navegador (Agnóstica)¶

    1. Diagnóstico del Problema Actual¶

    Al utilizar la aplicación desde navegadores web (como Google Chrome u otros), la recomendación de instalación o banner PWA nunca se mostraba debido a:

    1. Race Condition en beforeinstallprompt (Chromium):
    2. Chrome/Edge emiten el evento beforeinstallprompt en el objeto window en los primeros segundos de la carga inicial de index.html.
    3. El listener estaba registrado únicamente en el onMounted de MainLayout.vue (/dashboard).
    4. El usuario inicia su navegación en / (Landing) o /#/login. Al autenticarse y entrar a /dashboard, el evento ya se había disparado y perdido. Chrome no lo reemite en cambios de ruta SPA.
    5. Descarte perpetuo en localStorage:
    6. dismissInstall() fijaba pwa_install_dismissed = 'true' permanentemente. Si se tocaba "Ahora no", nunca volvía a ofrecerse.
    7. Falta de soporte agnóstico multi-navegador:
    8. Safari (iOS), Firefox (Android/Desktop) y otros navegadores no implementan beforeinstallprompt. Requieren flujos diferenciados con instrucciones claras o acceso bajo demanda.
    9. Iconos del Manifest:
    10. src-pwa/manifest.json agrupaba los PNGs como "purpose": "any maskable". Chromium y Android recomiendan separar las entradas "any" y "maskable" para evitar que el instalador descarte el icono.

    2. Matriz de Comportamiento por Navegador y Plataforma¶

    Navegador / Plataforma Soporta Prompt Programático Mecanismo de Instalación Flujo de la App
    Chrome / Edge / Brave / Opera / Samsung (Android & Desktop) ✅ Sí (beforeinstallprompt) deferredPrompt.prompt() nativo Banner con botón directo "Instalar" + Botón en Drawer
    iOS / iPadOS Safari (WebKit) ❌ No Menú Compartir → "Agregar a pantalla de inicio" Banner con ícono ios_share + Diálogo con pasos visuales
    Firefox Android ❌ No (evento) / ✅ Sí (browser UI) Menú ⋮ de Firefox → "Instalar" Mensaje explicativo guiado ("Toca ⋮ y selecciona Instalar")
    Firefox Desktop / macOS Safari (Sonoma+) ❌ No programático Menú del navegador / "Archivo → Agregar al Dock" Guía contextual si el usuario solicita instalar desde el menú
    App ya instalada (Cualquier navegador) — Modo standalone activo Ocultar banner y botón de instalación completamente

    flowchart TD
    A[Carga de index.html] --> B{¿Está en modo Standalone?}
    B -- Sí --> C[No mostrar recomendación: App ya instalada]
    B -- No --> D[Captura temprana: window.__deferredPwaPrompt = e]
    D --> E[Inicialización de MainLayout]
    E --> F{Detección de Navegador / Capacidades}
    F -- Chromium con Prompt --> G[Banner: Botón 'Instalar' directo]
    F -- iOS / iPadOS WebKit --> H[Banner: 'Compartir → Agregar a pantalla de inicio']
    F -- Firefox Android / Otros --> I[Banner: 'Menú ⋮ → Instalar']
    E --> J[Menú Lateral: Opción persistente 'Instalar App']
    J --> K[Abre prompt nativo o Diálogo con instrucciones según el navegador]

    4. Especificación Técnica de Implementación¶

    A. Captura Temprana Universal (frontend/pymes/index.html)¶

    Garantiza que ningún navegador basado en Chromium pierda el evento beforeinstallprompt, sin importar si el usuario entra por Landing, Login o recuperación de contraseña: 

    <script>
  window.__deferredPwaPrompt = null;
  window.addEventListener('beforeinstallprompt', function(e) {
    e.preventDefault();
    window.__deferredPwaPrompt = e;
    window.dispatchEvent(new CustomEvent('pwa-prompt-ready'));
  });
</script>

    B. Detección y Flujo Multi-Navegador (frontend/pymes/src/layouts/MainLayout.vue)¶

    1. Detección Standalone universal: 
      const isStandalone = typeof window !== 'undefined' && (
  window.matchMedia('(display-mode: standalone)').matches ||
  (navigator as unknown as { standalone?: boolean }).standalone === true
);
    2. Detección de plataformas: 
      const isIOS = typeof window !== 'undefined' && (
  /iphone|ipad|ipod/i.test(navigator.userAgent) ||
  (navigator.platform === 'MacIntel' && navigator.maxTouchPoints > 1)
);
const isFirefoxAndroid = typeof window !== 'undefined' &&
  /firefox/i.test(navigator.userAgent) && /android/i.test(navigator.userAgent);
    3. Recuperación del Prompt: Al montarse MainLayout, si window.__deferredPwaPrompt existe, se asigna inmediatamente a deferredPrompt.value. También se escucha el evento 'pwa-prompt-ready'.
    4. Descarte Inteligente con Cooldown: En lugar de bloqueo eterno, dismissInstall() almacena un timestamp de expiración (ej. 7 días): 
      function dismissInstall() {
  showInstallBanner.value = false;
  const expireAt = Date.now() + 7 * 24 * 60 * 60 * 1000;
  localStorage.setItem('pwa_install_dismissed_until', String(expireAt));
}
    5. Banner Adaptativo:
    6. En Chromium: Texto "Instala PYMEQ para una experiencia más rápida" + Botón "Instalar".
    7. En iOS: "Instala PYMEQ: toca Compartir y luego 'Agregar a pantalla de inicio'".
    8. En Firefox Android: "Instala PYMEQ: abre el menú ⋮ de Firefox y selecciona 'Instalar'".
    9. Acceso Permanente en Menú Lateral (Drawer):
    10. Item "Instalar aplicación" (ícono sym_r_install_mobile) en el sidebar cuando !isStandalone.
    11. Si hay prompt disponible (deferredPrompt), ejecuta .prompt().
    12. Si no hay prompt (iOS, Firefox o desktop), abre un diálogo explicativo rápido con los pasos exactos para ese navegador.

    C. Estandarización de Iconos (frontend/pymes/src-pwa/manifest.json)¶

    Separar entradas PNG para máxima compatibilidad con todos los motores (Chromium, Gecko, WebKit): - icon-192x192.png con purpose: "any" - icon-192x192.png con purpose: "maskable" - icon-512x512.png con purpose: "any" - icon-512x512.png con purpose: "maskable"

    5. Plan de Verificación Multi-Navegador¶

    1. Google Chrome / Edge (Desktop & Android):
    2. Cargar desde /login y acceder al dashboard.
    3. Verificar que el banner superior aparece con el botón "Instalar".
    4. Al pulsar "Instalar", se abre el diálogo nativo del sistema.
    5. Safari (iOS / iPadOS):
    6. Cargar la app en Safari.
    7. Comprobar que el banner muestra las instrucciones de "Compartir → Agregar a pantalla de inicio".
    8. Firefox (Android):
    9. Cargar la app y comprobar las instrucciones específicas para el menú de Firefox.
    10. Acceso bajo demanda:
    11. Descartar el banner ("Ahora no").
    12. Verificar que en el menú lateral sigue disponible la opción "Instalar aplicación" y es completamente funcional.
    13. Validación Standalone:
    14. Una vez instalada y abierta como PWA, verificar que no aparece ningún banner ni botón de instalación.
